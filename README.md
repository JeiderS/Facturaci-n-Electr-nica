📄 Gestor de Facturación Electrónica

🚀 Aplicación web para la gestión de facturas utilizando Vite, JavaScript y Fetch API. Permite la consulta, filtrado y visualización de facturas desde una API de facturación electrónica.

🔹 Características
📜 Consumo de API para gestionar facturas electrónicas en tiempo real.
🔍 Filtros avanzados para buscar facturas por fecha, cliente o estado de pago.
⚡ Interfaz rápida y ligera gracias a Vite.
🎨 Diseño responsivo con CSS puro, asegurando compatibilidad en dispositivos móviles.
🔄 Actualización dinámica de la información sin recargar la página, utilizando Fetch API.

📦 Tecnologías Utilizadas
✅ Vite
✅ JavaScript (ES6+)
✅ Fetch API
✅ HTML5 y CSS3
